# Contributing

Thanks for helping improve Folder Color.

## Guidelines

- Keep the package editor-only.
- Avoid runtime dependencies.
- Keep changes small and focused.
- Open an issue before large behavior or API changes.
- Test changes in Unity before opening a pull request.

## Pull Requests

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Update documentation when behavior changes.
5. Open a pull request with a short explanation and screenshots if the UI changed.
